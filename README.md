## :sparkles: Overview

No more manual downloads, archive extraction or hunting for updates.

**Quake 3 Elite Launcher** is a dedicated launcher designed to simplify the installation and management of [Quake 3 Elite](https://mus1n.github.io/).

Instead of manually downloading files, unpacking archives and keeping your installation up to date, the launcher handles the process for you.

From installing the game to browsing servers and managing your personal content, everything is accessible through a single interface.

## :rocket: Main Features

### 01 / One-Click Installation

Install the Q3Elite core with a single click. Customize your installation by selecting optional components, including External Maps and Music Playlist.

### 02 / Easy Updates

Keep your installation up to date without manually searching for and replacing files. The launcher handles downloading and updating the necessary components.

### 03 / Server Browser

Browse available Quake 3 servers, check their status and monitor player activity. Access your preferred game modes and servers directly from the launcher.

### 04 / Player Content Management

Manage your personal Quake 3 content without navigating through game directories.

- Screenshots
- Demos
- Configuration files
- Custom maps

### 05 / Integrated Q3Elite Experience

Everything you need for a modern Quake 3 setup, including the XQ3E engine, OSP2-BE, enhanced textures, updated maps, models, skins and HUDs.

### 06 / Customizable Interface

Choose between two visual themes designed for different preferences.
